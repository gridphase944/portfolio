## 公開方針

- 過去コードは全面的に書き直さず、当時の実装をできるだけ残しています。
- 公開にあたり、個人情報・機密情報・環境依存情報を除外し、公開範囲と説明を整理しています。
- 実データや学習済みモデルなど、公開しないファイルがあるプロジェクトもあります。
- 詳細な設計・評価・制約は各プロジェクトのREADMEに記載します。
